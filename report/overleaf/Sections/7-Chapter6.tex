\subsection{Vai trò của Node.js, npm và Vite}

Smart contract chạy trên blockchain, còn giao diện chạy trên \emph{trình duyệt}. Node.js \textbf{không phải máy chủ của ứng dụng}; nó là công cụ phát triển:

\begin{itemize}[leftmargin=1.5em]
    \item \textbf{Node.js (v24.11.0):} chạy JavaScript ngoài trình duyệt, dùng để chạy Vite.
    \item \textbf{npm (11.6.1):} cài các thư viện khai báo trong \code{package.json} (React, Vite, web3.js).
    \item \textbf{Vite:} \code{npm run dev} biên dịch JSX và phục vụ giao diện tại \code{http://localhost:5173} (hot reload);
          \code{npm run build} đóng gói vào \code{dist/}.
\end{itemize}

\begin{lstlisting}[style=ShellStyle, caption={Cài đặt và chạy frontend}]
cd frontend
npm install          # install React, Vite, web3.js, ...
npm run dev          # dev server at http://localhost:5173
\end{lstlisting}

Mã có \code{import Web3 from "web3"}, nên web3.js được khai báo trong \code{dependencies} (\code{"web3": "\^{}4.16.0"}).
Vì \code{CONTRACT\_ADDRESS} đã khai báo, ứng dụng tự chạy ở chế độ On-Chain.

\subsection{MetaMask ký giao dịch và trả phí gas}

\begin{itemize}[leftmargin=1.5em]
    \item \textbf{Hàm đọc (\code{view}):} chạy bằng \code{eth\_call} trên nút RPC; \emph{không ký, không mất gas}.
    \item \textbf{Hàm ghi:} tạo giao dịch. MetaMask hiện \emph{Transaction request} (mạng, hợp đồng, \emph{Amount}, \emph{Network fee});
          khi nhấn \emph{Confirm}, MetaMask \textbf{ký bằng khóa riêng} (khóa không rời khỏi ví) rồi phát lên mạng.
    \item \textbf{Phí gas} $=$ gas tiêu tốn $\times$ giá gas (wei/gas), \textbf{do người gửi trả} cho validator, tách biệt với tiền vé;
          thao tác ghi nhiều ô nhớ tốn gas hơn. Với \code{bookSeats}, \code{msg.value} vào số dư hợp đồng nên tổng chi của khách $=$ tiền vé $+$ phí gas.
\end{itemize}
