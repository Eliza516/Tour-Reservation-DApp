# Báo cáo Đề 36 — Tour Reservation DApp (LaTeX)

Thư mục này là một project Overleaf hoàn chỉnh.

1. Nén **nội dung** thư mục `overleaf/` thành `.zip` (hoặc dùng file `overleaf.zip` kèm theo) rồi Overleaf → *New Project → Upload Project*.
2. Compiler: **pdfLaTeX** (mặc định). Main document: `main.tex`.
3. Tìm các chỗ chữ **đỏ** `[...]` (trang bìa: học phần, giảng viên, họ tên, MSSV, lớp) và điền thông tin của bạn.

Cấu trúc: `main.tex` · `neu.sty` (template) · `Sections/` (bìa + 8 chương + phụ lục) · `Images/` (ảnh minh chứng + logo) · `Code/` (mã nguồn được nhúng bằng `\lstinputlisting`) · `main.bib`.
